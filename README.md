# Floodguardkz

Build a professional web application called FloodGuard.

It is an intelligent flood monitoring and
early warning platform designed for small
rivers and communities with limited
hydrological infrastructure.

The platform should include:

1. Main Dashboard
- Current water level
- Water level trend
- Temperature
- Weather conditions
- Current risk status

2. Monitoring
- Historical water level chart
- Daily measurements
- Water level changes over time

3. Flood Prediction
- Predicted water level
- Forecast time horizon
- Risk probability
- Explanation of prediction

4. Map
- Monitoring station locations
- River monitoring points
- Risk zones

5. Alerts
- Warning history
- Alert severity
- Date and time

Design:
Professional environmental technology SaaS.
Dark navy blue and light blue color palette.
Clean, modern interface.
Responsive desktop and mobile design.

Important:
Use clearly labeled DEMO DATA initially.
Do not present simulated measurements or
predictions as real-world observations.
Keep the architecture ready for future
integration with ESP32 sensors and ML models.
